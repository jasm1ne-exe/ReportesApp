# Borrador de prototipo #
### El frontend esta hecho en html, css y javascript. Para el backend se uso firebase.  
Este borrador tiene:
- Mapa de leaflet que centra la ubicacion segun la geolocalizacion del ordenador, o bien en las coordenadas del centro de Magdalena, Jal si el ordenador no concede el permiso de ubicacion
- Un formulario para enviar reporte
- Los reportes se vizualizan en el mapa
- Conexion a firebase
- Un panel administrativo para revisar los reportes
- Dashboard generico con chart.js
